Four components, one loop. The demo customer sites emit security events and answer our marked probes using toggleable weakness flags — never real data. Everything lands in Keewano, our per-customer event store: every event is validated against a frozen contract, evidence is write-once so findings stay reproducible, and reads are tenant-scoped slices, so no query can cross customers. Keewano feeds the security memory: a page per customer, plus a privacy-gated shared-intelligence page. The attack harness reads that memory and the event history, the LLM planner — Gemini — picks scenarios from a fixed catalog, the probe engine fires them, a deterministic verifier judges them, and confirmed findings wait at a human approval gate. Verdicts and evidence go straight back into Keewano, and the loop starts again.
